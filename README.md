## Supported Gestures

- Swipe Up
- Swipe Down
- Swipe Left
- Swipe Right
- Rotate Clockwise (CW)
- Rotate Counter-Clockwise (CCW)
- Tap
- Double Tap
- Triple Tap
- Hold
