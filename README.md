# BH1750 Demo Collection

This repository contains multiple BH1750-related projects, each maintained in a separate branch.

## Branches

### `BH1750_2SL_Entry`

The first project I built when starting my engineering studies. It was developed as the entry test project for Sensor Lab (HUST).

```bash
git clone -b BH1750_2SL_Entry --single-branch https://github.com/hphuc15/BH1750_Demo.git
```

### `BH1750_Arduino`

A simple BH1750 implementation using the Arduino framework. Primarily created for experimentation and learning.

```bash
git clone -b BH1750_Arduino --single-branch https://github.com/hphuc15/BH1750_Demo.git
```

### `BH1750_ESP_IDF`

A BH1750 implementation based on ESP-IDF. This is currently the most well-structured version and serves as both an application example and a reference integration for:

* `hphuc15/bare_drivers`
* `hphuc15/WiFiManager`

```bash
git clone -b BH1750_ESP_IDF --single-branch https://github.com/hphuc15/BH1750_Demo.git
```
